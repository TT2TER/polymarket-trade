# Handoff: Polymarket 持仓监控侧边栏 · UI 重设计

## Overview
这是 Polymarket 持仓助手 Chrome 扩展(MV3 Side Panel)的**侧边栏 UI 全面重设计**。目标是把原本较朴素的界面,换成一套**量化交易终端风格**:折叠态密集流(一屏纵览所有持仓)+ 点击展开操作区(交易 / 止损 / 盘口 / 挂单)。功能范围与现有扩展完全一致(只读监控 + 四种卖出 + 自动止损 + 盘口 + 挂单 + 已结算赎回),**仅重做视觉与交互层**,不改变后台/数据逻辑。

设计同时提供**深色 + 浅色(白天模式)**两套配色,通过设置面板的「主题」实时切换。

## About the Design Files
本包内的文件是用 **HTML 制作的设计参考稿**(展示目标外观与交互的原型),**不是可直接拷贝进生产环境的代码**。它们用一个内部的轻量模板运行时(`support.js` + `.dc.html`)渲染,**该运行时不属于交付目标**。

任务是:**在现有代码库的技术栈内,按其既有模式重建这些设计**。本项目已有明确技术栈(见 `polymarket-trade/`):

- **Vite + CRXJS + React + TypeScript + Zustand**
- 数据层:`data-api`(持仓)、CLOB `WebSocket`(实时盘口)+ REST(下单/撤单)
- 既有组件目录:`src/sidepanel/components/`

**请把设计映射到现有 React 组件上重写其 JSX + 样式**,复用现有 store(`useMonitorStore`)、i18n(`@/shared/i18n`)、计算函数(`@/lib/calc/pnl`)与消息协议。不要引入新框架,不要照搬 `.dc.html`/`support.js`。

## 设计语言(必须遵守)
- **红涨绿跌(中国习惯)**:盈利/上涨 = 红;亏损/下跌 = 绿。**与 Polymarket 默认相反**,务必按此。
- **黄色 = 目标语义**:仅用于「回本翻倍价 / 目标倍数」相关标记(2× 刻度、目标价标签)。**不要把黄色用于其它含义**。
- **蓝色(Poly 淡蓝)= 赎回 / 已结算**:已结算徽章、「在 Polymarket 赎回」链接、设置「保存」主按钮。
- **青色 = 系统/实时状态**:LIVE 指示点。
- 字体:数据/数字用 **IBM Plex Mono**,标题/标签/正文用 **Archivo**(可替换为代码库既有等宽 + 无衬线字体;现有项目用 Inter,可保留 Inter 作正文,数字强烈建议用等宽)。
- 密度:紧凑专业终端风。折叠行高约 64–72px。

## 关键算法 / 公式

### 回本翻倍价(目标价)
`目标价 = 倍数 × 均价`,倍数默认 `[2,3,5]`(可配)。`目标价 > $1` 标记「不可达 / 封顶」(Polymarket 价格上限 $1)。与现有 `multiplePrice()` 一致。

### 折叠行进度条(入场 → 目标 N×)
- 轨道代表 `入场价 → 目标价(N×均价,封顶 1.00)`。
- 填充 = `clamp((现价 − 入场) / (目标 − 入场), 0, 1)`。
- 若 `2×` 落在区间内,放一个黄色刻度:`pos2x = 入场 / (目标−入场) × 100%`,仅当 `2× < 目标` 且 4% < pos2x < 97% 时显示。
- 标签:左「IN 入场¢」,右「目标 N× 目标价¢」(黄)。
- **目标倍数 N 是每个持仓独立的状态**,展开操作区的「目标倍数」滑块与该折叠行进度条**双向实时联动**(改一处,另一处同步)。

### 非线性「目标倍数 N」滑块(0–100 位置 ↔ 倍数)
让 1–3× 细调、3× 以上对数压缩到最高 20×:
```
NMAX = 20
posFromN(N) = N <= 3 ? (N-1)/2*60 : 60 + ln(N/3)/ln(NMAX/3)*40
nFromPos(p) = p <= 60 ? 1 + p/60*2 : 3 * (NMAX/3)^((p-60)/40)
// N 四舍五入到 0.1
```
即前 60% 轨道线性映射 1→3×,后 40% 对数映射 3→20×。刻度 `1×(0%) 2×(30%) 3×(60%) 5× 10× 20×(100%)` 按 `posFromN` 定位。

### 盈亏 / 隐含概率
沿用现有 `unrealizedPnl()`、`impliedProb()`;现价取最优买价 `bestBid`(无则 `curPrice`)。

## Interactions & Behavior
- **折叠行点击**:手风琴展开/收起操作区(同时仅一个展开)。chevron 旋转 180°。
- **盘口**:点击买1/卖1 行在「折叠(买1/卖1+深度条)」与「完整 5 档」间切换。
- **交易/止损 Tab**:切换,默认交易。
- **滑块**:卖出数量 / 目标倍数 / 止损三参数,拖动实时更新派生数值(份额、估算金额、目标价)。
- **主题切换**(设置→主题):`深色/浅色` 立即换肤;`跟随系统` 读 `prefers-color-scheme`。
- **模拟/实盘开关**(设置):切换头部与设置徽章(模拟=红 / 实盘=绿)。下单走现有 Dry-run + 二次确认逻辑。
- **悬停**:折叠行 hover 背景 `--c-rowhover`(深 `#10151b` / 浅 `#eef1f5`)。
- 所有下单/撤单/止损/赎回的实际行为沿用现有 store actions 与后台消息,**仅替换 UI**。

## State Management
复用现有 `useMonitorStore`(snapshot/positions/books/openOrders/authStatus/config/stopLossConfigs…)。新增的纯 UI 局部状态:
- `open`:当前展开的持仓 asset(手风琴)。
- 每持仓 `targetMultiplier`(N):建议存入 config 或 store(因为要在折叠行与展开区共享,且可持久化为用户偏好)。
- `theme` / `themeMode`:接现有 `config.theme`(system/dark/light)。
- 各滑块的临时值(卖出比例、N、止损窗口/阈值/比例)——可由现有 `OrderActions` / `StopLossPanel` 的本地 state 承接。
- `book` 折叠态、Tab(trade/stop)为组件局部 state。
