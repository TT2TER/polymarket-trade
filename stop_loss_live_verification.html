止损系统 · 实盘验收指导

抗插针止损重构(Phase 1 / 2a / 2b + 审查修复)已合并主干。本指导用于真金白银环境下的渐进式验收。核心原则:先模拟、后小额、再放大;始终留逃生开关。

⚠ 三条铁律
  1. 面板必须开着止损才生效——监控、半自动倒计时都在侧边栏里。关掉面板 = 无保护。
  2. 止损是减损,不是回本。真事件(进球)造成的重定价损失锁死,止损只防"从半山腰坐到底"与"被插针误割"。
  3. 单点必死的盘(如"全场比分=X")一旦判死,任何止损都救不了——靠仓位管理/提前止盈/对冲,不靠止损。

一、实盘前:设置体检(必做)

项目建议为什么
dryRun先开(模拟)跑通,再关模拟下不会真下单,先确认 UI/触发/读出都正常
止损资金上限 stopLossMaxUsd设成你能接受的单次自动卖出额(如 $20)后台硬上限,超额直接拒单——防参数错配下的大额误卖
滑点 slippage默认 5%,薄盘可调高到 8–10%止损卖单限价地板=买一×(1−滑点);太小急跌时挂不出去,太大成交差
半自动确认 semiAutoMode头几次实盘建议开触发先弹卡片等你一键确认(10s 超时才自动执行),给你"看一眼再决定"的机会
模式 anchor盈利仓用激活跟踪;想"亏到X%才走"用固定离场三种模式决定止损线由谁算(峰值/成本)

二、渐进式上线(分三阶段)

A

模拟软测 无资金

dryRun 开。把 1–2 个真实持仓武装,放着观察一段(尤其行情波动时)。

  • 武装后徽章从 未武装·预览 → 跟踪中/未激活/...,止损线/参考价/距离随行情实时刷新
  • 顶部绿条 ⛨ 止损已武装 · 距 X% · 卖 Y% 数值合理且更新(不再是 0s/0%)
  • 价格插针(瞬时尖刺)时不触发;持续真跌才进入 确认中 N.Ns 倒计时
  • 触发后面板显示 (模拟) 结果、无报错;撤防后徽章立刻回 未武装·预览
  • 半自动开启时:触发弹置顶卡片 + 系统通知,测 立即平仓 / 取消 / 等10s自动 三条路径
过关标准:至少经历一次真实的"插针没割 + 真跌触发",且读出/徽章/卡片全程正确。没有日志系统,只能靠面板读出与通知观察,所以请耐心盯一段。
B

最小额实盘 极小资金

关 dryRun。用能整仓亏掉也无所谓的最小仓位(几美元),半自动开。

  • 触发时收到卡片/通知,立即平仓能真实成交,面板显示真实订单结果(非模拟)
  • 成交价落在买一×(1−滑点)地板之上,与"距离/止损线"读出大致自洽
  • 故意制造"取消":取消后持续破位 ~30s 会重新弹确认(snooze),不是永久静默
  • 若遇到急跌零成交(FAK 没撮合):应在 ~15s 后自动重试,而不是静默禁用
红线:一旦出现"成交价离谱""无故触发""撤防后还在卖""卖出量不对",立即撤防、关面板、停手,把现象记下来反馈。
C

逐步放大 正常资金

B 阶段稳定后,逐步加仓;熟悉的、流动性好的盘可改全自动(关半自动),薄盘/重仓保持半自动。

  • 每次只放大一档,观察一个完整事件周期再加
  • stopLossMaxUsd 随仓位同步上调,始终 ≥ 单次预期卖出额(否则会被拒单)
  • 重仓/关键时刻优先半自动;垃圾时间、低波动可全自动

三、Polymarket 体育盘 · 场景对照

验收时刻意覆盖这几类,确认行为符合预期:

场景预期正确行为
平静持仓 + 单根插针(买一瞬时跳水又回弹)不触发 中位数参考价吃掉单针,dwell 不计满
临门高潮 · 来回剧烈波动不被扫 波动自适应自动放宽阈值,正常抖动不触发
真进球/红牌 · 持续下跌触发出场 破线持续 → 确认 → 卖出;深跌时确认更快(速度自适应)
盈利仓回撤到成本附近(激活跟踪)保本不亏 止损线=峰值×(1−阈值)且不低于成本,最坏保本出
极低价长尾仓(<0.10)不被噪声斩 关闭百分比跟踪,只走绝对地板;涨过 0.10 才启用跟踪
单点比分判死 / 临近结算归零救不了 流动性蒸发,止损无能为力——靠提前减仓/对冲

四、面板读法速查

读出含义
止损线当前会触发卖出的价位(已武装=实时;未武装=按当前设置的预览)
参考价近几拍买一的中位数(抗插针),不是裸买一
距离现价距止损线的百分比。绿>10% / 黄0–10% / 红已破
徽章 跟踪中/未激活/保本贴地/低价长尾当前所处的止损"阶段"(已武装时为实时状态)
徽章 确认中 N.Ns已破线、正在等持续确认(dwell 倒计时);走完才真触发
徽章 冷却中刚触发过,冷却期内不重复触发

提示:启用浮盈 / 最大亏损这两个滑块只在"激活前"那段生效;盈利仓已激活后,止损线由峰值、阈值、成本地板决定,调这俩不动线属正常。

五、已知边界(务必知情)

  • 面板关闭即无保护:整套监控与半自动倒计时都在侧边栏。要保护就别关面板。
  • 半自动的 10s 兜底依赖面板在线:倒计时期间关/重载面板,这一次确认可能丢失(重启监控后对持续破位会重新触发)。
  • 急跌真空可能零成交:FAK 卖单在流动性蒸发时可能不成交,现已自动重试,但真空里仍可能拿不到价——这是市场决定,非 bug。
  • 无日志系统:目前只能靠面板读出 + chrome 通知观察;事后复盘能力有限。若实盘暴露需要,再单独加日志。
  • 结算/单点必死救不了(见铁律 3)。

六、出问题怎么办

  1. 立即撤防(关武装开关),必要时关面板停止一切自动动作。
  2. 记录现象:标的、时间、当时的止损线/参考价/距离/徽章、面板里的 lastResult/lastError 文案、以及你看到的成交。
  3. 切回 dryRun 复现。
  4. 把以上反馈给我,我在分支 feat/stoploss-redesign 的 worktree 里定位修复。
