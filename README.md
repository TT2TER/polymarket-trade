# Polymarket 持仓助手

一个用于 **Polymarket** 的 Chrome 扩展(Manifest V3,常驻**侧边栏 Side Panel**)。它把「同时盯多个持仓」和「一键卖出 / 自动止损」做到一屏之内,界面为**量化交易终端风格**(密集折叠流纵览 + 点击展开操作,等宽数字,默认红涨绿跌),支持中英双语与深/浅/跟随系统主题。

> ✅ **实盘交易已打通并默认开启**。适用于 Polymarket **「存款钱包(deposit wallet)」账户**(邮箱 / Magic 注册,ERC-1271 智能合约钱包,签名类型 `POLY_1271`),已端到端实盘验证(挂单 + 卖出 + 撤单成功)。**其他账户类型暂不支持**,见 [支持的账户类型](#支持的账户类型)。
>
> ⚠️ **本扩展会动用真实资金并使用你的私钥。** 默认即为**实盘**(下单会真实成交)。请仅对**只存放计划交易资金的小号**使用;每笔下单都有二次确认与单笔金额上限,但仍请谨慎。想先试手可在设置里打开「模拟交易(Dry-run)」。

## 它能做什么

- **多持仓监控**:按「事件」分组,一行纵览一个持仓的盈亏、份额、均价、现价、持仓价值;实时盘口(WebSocket 推送)。
- **四种卖出**:价格优先(被动挂单)、成交优先(立即吃单)、N 倍价挂单、回收 N 倍成本(部分减仓后剩余白嫖)。
- **撤单**:查看并撤销自己的挂单。
- **自动止损**:每个持仓单独武装,检测「瞬时急跌」自动抛出设定比例。
- **回本/翻倍价、回本进度条、封盘倍率**等盈利目标可视化。
- **护栏**:下单二次确认、单笔金额上限、止损独立上限、私钥仅本地加密、模拟交易开关。

## 支持的账户类型

| 账户类型 | 注册方式 | 是否支持实盘 |
|---|---|---|
| **存款钱包 / POLY_1271**(ERC-1271 智能合约钱包) | **邮箱 / Magic 登录**(本扩展面向的主流场景) | ✅ 支持 |
| Gnosis Safe(`POLY_GNOSIS_SAFE`) | 外部钱包(MetaMask 等)注册 | ❌ 暂不支持 |
| 老式代理(`POLY_PROXY`)/ 纯 EOA | — | ❌ 暂不支持 |
| Privy TSS 多签 | 部分较新的邮箱账户 | ❌ 无法支持(导出的「私钥」只是分片,签不出有效签名,只能用官网) |

> 扩展的签名类型固定为 `POLY_1271`,未做自动识别。**只读监控对所有账户都可用**;只有「下单 / 止损」要求上表中支持的账户。
> 不确定自己属于哪种?见 [常见问题排查](#常见问题排查) 里的账户自检脚本。

## 从零部署(安装)

需要 **Node 18+**(开发用 Node 22)与 **Chrome**(或基于 Chromium 的浏览器)。

```bash
# 1. 拉取代码后,在项目根目录:
npm install

# 2. 构建生产版本,产物输出到 dist/
npm run build
```

加载到 Chrome:
1. 地址栏打开 `chrome://extensions`,右上角开启「**开发者模式**」。
2. 点「**加载已解压的扩展程序**」,选择项目里的 **`dist/`** 目录。
   - (若你拿到的是发行版 `.zip`,先解压,再选解压出的文件夹。)
3. 点浏览器工具栏的扩展图标 → 打开 **Side Panel(侧边栏)**。建议把扩展固定到工具栏。
4. 升级:重新 `npm run build` 后,回 `chrome://extensions` 点本扩展的「**重新加载**」,并重开侧边栏。

> 调试:`chrome://extensions` → 本扩展 → 点 **Service Worker** 链接,可打开后台控制台看日志/报错。

## 首次设置

打开侧边栏后,点顶部「**设置**」展开。

### 1. 填监控地址(必填)
- 填你的 **Polymarket 存款 / 代理钱包地址**(`0x...`)。这是**持有你资金和持仓的地址**,也会作为下单的 funder。
- 在哪找:打开 `polymarket.com` → 个人资料 / 设置,里面标着「**仅供 API 使用 / 请勿向此地址发送资金**」的那个 `0x` 地址就是它(名字叫 deposit / proxy wallet)。
- 这是**公开地址,不是私钥**。填完即可看到持仓与盈亏(只读不需要私钥)。

### 2. 启用交易(导入私钥)——仅下单/止损时需要
> 只读监控**不需要**这一步。

1. 从 Polymarket 导出私钥:**账户设置 → Export Private Key**(或访问 `reveal.magic.link/polymarket`)。提示「导出私钥以直接控制你的资金」。
2. **强烈建议先用只放少量资金的测试小号。**
3. 在侧边栏「**交易访问**」区,粘贴私钥 + 设置一个**解锁密码(≥8 位)** → 导入。
4. 看到绿色 **「交易已启用 / CLOB auth ready」** 即成功。会显示由私钥派生的 **Signer(EOA)地址** —— 它 **≠** 你上面填的代理钱包地址,这是**正常的**(签名者与资金钱包本就是两个地址)。
5. **会话级解锁**:每次重开浏览器输一次密码解锁;可随时「锁定」;「忘记密钥」会清除本地密文。

> 私钥经 **PBKDF2(20 万次)+ AES-256-GCM** 加密,只存本机 `chrome.storage.local`;解锁后的明文仅驻留 `chrome.storage.session`(关浏览器即清),**绝不**同步、**绝不**打印或外发。

### 3.(可选)交易设置
- **模拟交易(Dry-run)**:默认**关闭**(即实盘)。想先空跑流程就打开它。
- **最大订单 USD**:单笔手动下单金额上限(默认 100),超限拦截。
- **止损最大 USD**:止损单独立上限(默认 1000),不受手动单上限约束。

## 监控:看懂每一行

- **汇总条(顶部)**:总持仓价值 / 今日(滚动 24h 盈亏)/ 未实现盈亏。今日值低频拉取,可在设置关闭。
- **每个持仓一行**(按事件分组的折叠流):
  - YES/NO 徽章、市场标题、**盈亏%**、`份额 @ 均价¢ → 现价¢`、持仓价值、**总盈亏 $**。
  - 总盈亏 $ = 已实现(API)+ 未实现(按最优买价实时算);盈亏% 取未实现(盯市)。
  - **回本进度条**:入场 → 目标(N×)的双锚点进度;目标接近 $1 时切「封盘锚定」(右端固定 100¢)。
- **点任意一行**手风琴展开操作区(同时只展开一个),里面有:盘口 LOB、卖出操作、撤单、止损 Tab。
- **回本价 / 翻倍价**:`2x / 3x / 5x`(倍数可配)= 倍数 × 均价;超过 $1 标「不可达」。**封盘 N×** = 1/均价(市场结算到 $1 时相对均价的盈利倍数)。
- **实时行情**:盘口/价格走 CLOB WebSocket 实时推送;持仓信息按间隔轮询。工具栏「↻ 刷新」可立即重拉。
- **已结算 · 可赎回持仓**:单独标注,提供「在 Polymarket 赎回 ↗」入口(跳官网领收益)。

## 卖出:四种方式的逻辑

在某个持仓展开后的 **交易(Trade)** 区选择。卖出数量用**滑块**,右上角股数可**键盘直接输入**(与滑块联动);按钮上内联显示关键数值。**每次点卖出都会弹二次确认**(显示方向/价格/数量/预计金额),确认后才真正提交。

| 方式 | 定价 | 成交特性 | 适合 |
|---|---|---|---|
| **价格优先** | 挂在当前**最优卖价**(post-only 被动单) | **不穿价、不立即成交**,排队等买家。追求卖得贵 | 不急、想吃到好价 |
| **成交优先** | 定在当前**最优买价**(FAK,只吃顶档) | **立即成交**,让出价差换确定性,吃不到的部分撤掉 | 想马上出货 |
| **N 倍价挂单** | 在 `N × 均价`(向上取整到 tick)挂限价卖单 | 被动等价格涨到目标 | 设定盈利目标挂着 |
| **回收 N 倍成本** | 按现价卖出 `数量 = N×成本 / 现价` | 到手现金 = N×成本,**其余份额继续持有** | 落袋本金、剩余白嫖 |

**「回收 N 倍成本」细节**:卖出份数 `q = N·均价·份额 / 现价`,使现金回收 = N × 成本。
- 可行条件:现价 `p ≥ N × 均价`(即 `q ≤ 全部份额`)。
- 若现价不够(`q > 份额`):自动**封顶为全仓**并提示「卖全仓也不足 N 倍成本」。
- `N = 1` 就是「**取回本金,剩余白嫖**」。

> 提示:超过「最大订单 USD」会被拦截;首次实盘建议用很小的量先走一遍。

## 自动止损:原理与操作

> ⚠️ 止损监控**只在侧边栏打开时运行**(关闭侧边栏即暂停,不在后台 7×24 盯盘)。

### 操作步骤
1. 展开某个持仓 → 切到 **止损 Tab**。
2. **武装(arm)** 该持仓(opt-in,逐仓单独开)。武装后该行显示 **⛨** 徽章。
3. 用 **4 个滑块**调参(也可用随仓位变化的自动默认值):
   - **滚动窗口**(1–120s):观察急跌的时间窗。
   - **跌幅阈值**(3–50%):窗口内从峰值回撤多少触发。
   - **触发卖出比例**(5–100%):触发时抛出持仓的百分之多少。
   - **滑点**(0–50%):见下。

### 触发逻辑(重要)
- 检测的是「**滚动窗口内、价格从峰值的回撤** ≥ 跌幅阈值」—— 衡量的是**窗口内的急跌**,**不是**相对你成本价的浮亏。价格取最优买价。
- 触发后**自动以「成交优先」抛出**设定比例:限价 = `最优买价 ×(1 − 滑点)` 向下取整到 tick,用 **FAK 向下扫多档**,确保急跌时也能成交而不是被 Kill 掉。
- **遵守全局模拟开关**:若开着 Dry-run,只签名 + 弹桌面通知「本应卖出」,**不真卖**;关闭 Dry-run 且该仓已武装才真卖。
- 触发后 **60s 冷却**,且需跌幅回落到阈值下方才重新待命。
- 止损单走**独立上限** `止损最大 USD`,不受手动单 `最大订单 USD` 限制。

## 安全护栏与开关

- **默认实盘**:`dryRun = false`。要空跑请在设置打开「模拟交易」(开启后下单只构造+签名、不提交)。
- **下单二次确认**:确认弹窗由后台用一次性 nonce 强制,非仅前端约定。
- **单笔金额上限** `最大订单 USD` + **止损独立上限** `止损最大 USD`,均在后台强制校验。
- **前置条件**:仅在「交易已启用(CLOB 认证就绪)」时才可下单。
- **私钥仅本地**:加密存储,会话级解锁,绝不上传/同步/打印。浏览器扩展安全性不及硬件钱包,**请只放计划交易的资金**。

## 常见问题排查

- **填了地址看不到持仓**:确认填的是**存款/代理钱包**地址(holds positions 的那个),不是你的 EOA 签名地址;且该账户确有持仓。
- **导入私钥后没变绿 / 报错**:密码错误会明确报错;若反复失败,可能账户是 Privy TSS(导出的不是完整私钥),无法用 SDK 下单。
- **下单报 `maker address not allowed` / `signer ... API KEY`**:几乎都是账户/签名类型不匹配。本扩展固定 `POLY_1271`,只对存款钱包账户有效。
- **下单成功但很快被撤/不成交**:实盘下单请**直连家庭网络**,避免数据中心/VPN 出口 IP 被风控(挂上后约 10 秒被服务端撤销)。
- **止损没触发**:确认①侧边栏开着 ②该仓已武装 ③确实发生了窗口内急跌(而非缓慢浮亏)。
- **账户类型自检(进阶)**:仓库 `scripts/test-deposit-wallet.mjs` 是一个**开发诊断脚本**(不随扩展打包):
  ```bash
  cp scripts/deposit-wallet.env.example scripts/.env   # 填入 PRIVATE_KEY
  node --env-file=scripts/.env scripts/test-deposit-wallet.mjs
  ```
  它会派生你的 EOA、检查存款钱包是否部署、逐个签名类型探测真实余额,告诉你账户属于哪种、应用哪个签名类型。`scripts/.env` 已被 `.gitignore` 忽略,私钥不会进 git。

## 支持范围与下单方案(技术)

当前采用的方案(`src/lib/trading/clobClient.ts`),已实盘端到端验证(挂单 `status: live`、卖出成交、撤单成功;验证于 2026-06-19):
- **签名类型固定为 `POLY_1271 (3)`**;**funder = 存款钱包地址**(即设置里的「代理钱包地址」)。
- **signer 使用 viem `walletClient`**(由导出私钥派生的 owner EOA 签名);订单经 ERC-7739 包裹,由存款钱包通过 ERC-1271 验签(maker = signer = 存款钱包)。
- **CLOB API Key 绑定 owner EOA**(`createOrDeriveApiKey`)—— 这是官方设计(见 [Polymarket/ts-sdk#73](https://github.com/Polymarket/ts-sdk/issues/73)),并非需修复的 bug;早期「存款钱包无法下单」的真因是签名类型用错(用了 `POLY_PROXY 1`)。

**暂不支持**:其他钱包/签名类型(Gnosis Safe=2、老式代理=1、纯 EOA=0;未做自动识别)、Privy TSS 账户(无法签名)、以及迁移到统一 SDK `@polymarket/client`(当前方案已可用,暂不采用)。

## 技术栈与结构

- Vite + CRXJS + React + TypeScript + Zustand;**`@polymarket/clob-client-v2`**(CLOB V2)+ **`viem`**(钱包/签名);自托管 `@fontsource/inter` + `@fontsource/ibm-plex-mono`。
- 数据来源:`data-api`(持仓)、`user-pnl-api`(汇总条 24h 盈亏)、CLOB `WebSocket`(实时盘口)+ REST(tick size、neg-risk、下单、撤单)。全部公开只读(下单/撤单除外)。
- 目录:`src/background`(Service Worker:认证/签名/下单/撤单/止损执行)、`src/sidepanel`(React UI + store + 组件)、`src/lib`(api / datasource / calc / trading / crypto / stoploss)、`src/shared`(config / i18n / messages / 止损配置 / 目标倍数)。
- 样式:`src/sidepanel/styles/tokens.css`(设计令牌:主题 + 涨跌语义色)+ `base.css`(reset + 共享原子)+ 各组件 co-located `*.css`。
- 开发自测(不进发行包):`node scripts/check-crypto.mjs`、`check-orders.mjs`、`check-stoploss.mjs`;账户诊断 `scripts/test-deposit-wallet.mjs`、`scripts/verify-order.mjs`。
