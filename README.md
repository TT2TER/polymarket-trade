# Polymarket 持仓助手

一个用于 **Polymarket** 的 Chrome 扩展(Manifest V3,侧边栏 Side Panel),用于**同时监控多个持仓**,并在面板内**更快地卖出与自动止损**。界面为**量化交易终端风格**(折叠密集流一屏纵览 + 点击展开操作区,数字用 IBM Plex Mono 等宽,默认红涨绿跌),支持中英双语与深/浅/跟随系统主题。

> ⚠️ **当前实盘下单受上游限制(见[已知限制](#已知限制)):新版 Polymarket「存款钱包(deposit wallet)」账户暂时无法在扩展内真实下单。** 因此目前以**监控 + 计算**为主;监控/盈亏/止损检测/UI 全部可用,默认开启「模拟交易(Dry-run)」。
>
> ⚠️ 涉及真实资金与私钥。请仅对**只存放计划交易资金**的账户使用,确认无误后再切实盘。

## 功能一览

### 监控(只读)
- **多持仓面板**:按「事件」分组的**折叠密集流**(一行纵览一个持仓:YES/NO 徽章、标题、盈亏%、`份额 @ 均价¢ → 现价¢`、持仓价值、总盈亏$),点击任意行手风琴展开操作区(同时只展开一个)。
- **汇总条**(顶部):**总持仓价值** / **今日(滚动 24h P&L)** / **未实现盈亏**;今日值经 `user-pnl-api` 低频拉取(与实时行情解耦),可在设置关闭。
- **总盈亏含已实现**:行内 $ 金额 = 已实现(API)+ 未实现(按最优买价实时算);展开区给「已实现 / 未实现 / 合计」拆解。盈亏% 取未实现(盯市)。
- **回本/翻倍价**:`2x / 3x / 5x`(倍数可配)目标价 = 倍数×均价;超过 $1 标记「不可达」。另显示**封盘倍率**(`封盘 N×` = 1/均价,市场结算到 $1 时相对均价的盈利倍数)。
- **回本进度条**:折叠行用双锚点进度条展示 入场 → 目标(N×);当目标价接近 $1 时改为「封盘锚定」(右端固定 100¢,黄色目标线按真实比例右移)。
- **盘口 LOB**(展开区):默认折叠为买1/卖1 + 深度条,点击展开完整 5 档(各档深度条,最优档高亮)。
- **实时行情**:通过 Polymarket CLOB WebSocket 实时推送盘口/价格(非轮询),持仓信息按间隔轮询。
- **手动刷新**:工具栏「↻ 刷新」立即重新拉取。
- **已结算 · 可赎回持仓**:单独标注,提供「在 Polymarket 赎回 ↗」入口(打开 portfolio 领取收益)。可在设置中隐藏。

### 交易(四种卖出 + 撤单)
> 说明:下列交易能力已实现并可在**模拟模式**下走完整流程;**实盘**对「存款钱包」账户暂被上游 SDK 卡住(见[已知限制](#已知限制))。
- **价格优先**:被动挂单(post-only,挂在最优卖价),追求价格、不穿价,不保证立即成交。
- **成交优先**:吃当前最优买价(FAK,部分成交即止),让出价差换**立即成交**。
- **N 倍价挂单**:在 `N×均价`(向上取整到 tick)挂限价卖单。
- **回收 N 倍成本**:卖出 `数量 = N×成本 / 现价`,使到手现金 = N×成本,**其余份额继续持有**(N=1 即"回本后剩余白嫖")。
- **撤单**:查看并撤销该持仓的挂单(支持单笔与一键撤销)。
- **滑块化操作**:卖出数量用滑块,右上角股数支持**键盘直接输入**(与滑块双向联动);目标倍数 N 用非线性滑块(前 3× 细调、之后对数压缩),**拖到「不可达」(N×均价 > $1)即硬停**。按钮上内联显示关键数值(如「价格优先 48¢」「成交优先 47¢」「N 倍卖出 X 份」「卖出 X 股回收 N 倍」)。

### 自动止损(瞬时下跌)
- **每个持仓单独武装**(opt-in)才生效;止损 Tab 用 **4 个滑块**:滚动窗口(1–120s)、跌幅阈值(3–50%)、触发卖出比例(5–100%)、**滑点**(0–50%)。
- 检测:**滚动窗口内"从峰值的回撤" ≥ 跌幅阈值**即触发(注意:衡量的是窗口内急跌,**不是相对成本价的浮亏**);价格取最优买价。折叠行武装后显示 ⛨ 徽章。
- 触发:自动以「成交优先」抛出设定比例,**限价 = `最优买价 ×(1 − 滑点)` 向下取整到 tick**(FAK 向下扫多档,确保急跌也能成交而非被 Kill);**遵守全局 Dry-run**(模拟时只签名+桌面通知,不真卖);触发后 60s 冷却 + 需跌幅回落到阈值下才重新待命。
- ⚠️ 监控仅在**侧边栏打开**时运行(关闭侧边栏即暂停)。

### 安全护栏
- **私钥仅本地**:PBKDF2 + AES-GCM 加密存储,绝不上传/同步/打印;会话级解锁。
- **Dry-run 模拟开关**(默认开启):开启时下单只构造+签名、不提交。
- **下单二次确认**:确认弹窗显示方向/价格/数量/预计金额;确认由后台强制(一次性 nonce),非仅前端约定。
- **单笔金额上限**(`最大订单 USD`)与**独立止损上限**(`止损最大 USD`),在后台强制校验。
- 仅在「交易已启用(CLOB 认证就绪)」时才可下单。

### 界面
- **量化终端风**:全宽通栏无缝布局(无浮动卡片间隙),区块以分隔线 + 背景明暗分层;数字用 IBM Plex Mono 等宽,正文 Inter。
- **主题**:跟随系统 / 深色 / 浅色,实时响应系统切换。
- **涨跌配色**:A股(红涨绿跌,默认)/ 美股(绿涨红跌)切换,仅翻转「按盈亏着色」的部分(盈亏%/盈亏额、YES/NO 徽章、汇总条、进度条);模拟徽章、止损、盘口买/卖、卖出/撤单按钮等固定语义色不受影响。
- **中英双语**:设置内一键切换(默认中文)。
- 设置与「交易访问」面板默认折叠;折叠后的设置头部显示当前交易模式徽章(**模拟=红 / 实盘=绿**)。

## 安装与加载

需要 Node 18+(开发用 Node 22)。

```bash
npm install
npm run build      # 产物输出到 dist/
# 开发热更新:npm run dev
```

加载到 Chrome:
1. 打开 `chrome://extensions`,右上角开启「开发者模式」。
2. 点「加载已解压的扩展程序」,选择项目的 `dist/` 目录。
3. 点扩展图标打开 **Side Panel**(侧边栏)。
4. 调试:`chrome://extensions` → 本扩展 → 点 **Service Worker** 链接打开后台控制台查看日志/报错;改代码后回卡片点「重新加载」并重开侧边栏。

## 使用说明

### 1. 配置(设置)
点设置展开,填写:
- **代理钱包地址**:你的 Polymarket 主页地址(`polymarket.com/profile/0x...` 中的 `0x` 地址,公开,**不是私钥**)。用于拉取持仓,也作为下单的 funder。
- **主题 / 涨跌配色(A股·美股) / 语言 / 隐藏已结算持仓 / 显示汇总条**。(行情/持仓轮询间隔不在 UI 暴露,用内置默认值。)
- **交易设置**:模拟交易开关、最大订单 USD、止损最大 USD。(止损**滑点**已改为**每仓**设置,在各持仓的止损 Tab 内。)
- 保存后设置自动折叠;头部徽章显示当前为「模拟」或「实盘」。

### 2. 启用交易(导入私钥)
> 仅当你要在扩展内下单/止损时需要。只读监控不需要私钥。

1. 从 Polymarket 导出私钥:账户设置 → Private Key(或 `reveal.magic.link`)。建议先用**只放极少资金的测试小号**。
2. 在「交易访问」区粘贴私钥 + 设置解锁密码(≥8 位)→ 导入。
3. 看到绿色 **「交易已启用 / CLOB auth ready」** 即成功(私钥已派生 CLOB 凭据)。会显示由私钥派生的 **Signer(EOA)地址**——注意它 **≠** 你的代理钱包地址,这是正常的(代理钱包模式)。
4. **会话级解锁**:每次开浏览器输一次密码解锁;可随时「锁定」;「忘记密钥」清除本地密文。

### 3. 监控
填好地址后即显示持仓(按事件分组)、实时盘口与盈亏、回本/翻倍价。无持仓时显示空态。

### 4. 卖出
在持仓卡片的 **交易(Trade)** 区选择四种方式之一,填数量/价格/N → 弹确认框 → 确认。
- **模拟模式**下结果显示 `DRY RUN - 已签名…`(不提交);关闭 Dry-run 后才真实下单。
- 超过「最大订单 USD」会被拦截。建议先用小额实盘验证一次。

### 5. 撤单
在 **Open orders** 区查看挂单,单笔撤销或一键撤销该持仓挂单。

### 6. 自动止损
在持仓卡片的止损区:武装(可用自动默认或自定义窗口/阈值/卖出比例)。触发时按设置自动卖出(模拟模式下只通知不真卖),并弹桌面通知。**记得保持侧边栏打开**。

### 7. 赎回已结算持仓
市场结算后,持仓在赎回前仍会显示(代币仍在钱包)。点「在 Polymarket 赎回 ↗」前往 portfolio 领取收益。

## 安全说明

- 私钥经 PBKDF2(20 万次)+ AES-256-GCM 加密,仅存 `chrome.storage.local`;解锁后的明文仅驻留内存级 `chrome.storage.session`(随浏览器关闭清除),**绝不**写入同步存储、**绝不**打印或外发。
- 浏览器扩展环境的安全性不及硬件钱包,**请只放计划交易的资金**。
- 默认 Dry-run;实盘前请用小额验证全流程。

## 已知限制

- **实盘下单暂不支持「存款钱包」账户**:Polymarket 2026 新模型的「存款钱包(deposit wallet,ERC-1271 智能合约钱包)」下单需 `signatureType 3 (POLY_1271)` + ERC-7739 包裹签名 + L1 鉴权绑定存款钱包;而当前 TS SDK `@polymarket/clob-client-v2`(含最新版/预发布)的 API Key 派生仍绑到 EOA、未做 1271 包裹(上游 bug),导致这类账户下单被拒(`maker address not allowed, please use the deposit wallet flow`)。**因此当前以监控+计算为主,实盘交易暂缓。** 两条待选解法已记录在 `progress.md`:① 等上游修复后把签名类型切到 3;② 迁移到官方统一 SDK [`@polymarket/client`](https://github.com/Polymarket/ts-sdk)(`createSecureClient` 原生支持存款钱包)。监控/盈亏/止损检测/UI/模拟下单均不受影响。
- **止损/监控仅在侧边栏打开时运行**(关闭即暂停;不在后台 7×24 盯盘)。
- **链上赎回**未做扩展内一键执行,目前跳转 Polymarket 完成。
- 后台抛出的部分错误文案为英文(界面自有文案已中英双语)。
- **Safari 版**暂缓(后续基于 Chrome MV3 迁移)。

## 技术栈与结构

- Vite + CRXJS + React + TypeScript + Zustand;**`@polymarket/clob-client-v2`**(CLOB V2)+ `ethers` v5;自托管 `@fontsource/inter` + `@fontsource/ibm-plex-mono`。
- 数据:`data-api`(持仓)、`user-pnl-api`(汇总条 24h P&L)、CLOB `WebSocket`(实时盘口)+ REST(tick size、neg-risk、下单、撤单)。
- 样式:无单体 CSS —— `src/sidepanel/styles/tokens.css`(设计令牌:深/浅主题 + 涨跌配色语义色)+ `base.css`(reset + 共享 `.pq-*` 原子)+ 各组件 co-located `*.css`。
- 目录:`src/background`(Service Worker:认证/签名/下单/撤单/止损执行)、`src/sidepanel`(React UI + store + 组件)、`src/lib`(api / datasource / calc / trading / crypto / stoploss)、`src/shared`(config / i18n / messages / 止损配置 / 目标倍数)。
- 离线自测:`node scripts/check-crypto.mjs`、`check-orders.mjs`、`check-stoploss.mjs`。

更多:测试清单见 [`TESTING.md`](./TESTING.md);开发进展与设计决策见 [`progress.md`](./progress.md)。
